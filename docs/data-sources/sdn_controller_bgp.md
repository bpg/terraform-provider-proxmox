# Data Source: proxmox_sdn_controller_bgp

Reads the BGP controller configuration, which configures the Free Range Routing (frr) BGP router of a node. The data source reports the configuration desired by the SDN API, not the operational state of the BGP sessions.

## Example Usage

```terraform
data "proxmox_sdn_controller_bgp" "example" {
  id = "bgp1"
}

output "data_proxmox_sdn_controller_bgp" {
  value = {
    id        = data.proxmox_sdn_controller_bgp.example.id
    node_name = data.proxmox_sdn_controller_bgp.example.node_name
    asn       = data.proxmox_sdn_controller_bgp.example.asn
    peers     = data.proxmox_sdn_controller_bgp.example.peers
    ebgp      = data.proxmox_sdn_controller_bgp.example.ebgp
  }
}
```

## Schema

### Required

- `id` (String) The unique identifier of the SDN controller

### Read-Only

- `asn` (Number) Autonomous System Number of the local BGP router.
- `bgp_multipath_as_path_relax` (Boolean) Whether different AS paths of equal length are considered for multipath computation.
- `digest` (String) Digest of the controller section.
- `ebgp` (Boolean) Whether eBGP is used (remote-as external) instead of iBGP.
- `ebgp_multihop` (Number) Maximum amount of hops for eBGP peers. Zero when not configured.
- `loopback` (String) Name of the loopback/dummy interface that provides the Router-IP.
- `node_name` (String) Name of the node this BGP controller is bound to.
- `peers` (Set of String) Set of BGP peer IP addresses for the BGP controller.
