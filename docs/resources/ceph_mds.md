# Resource: proxmox_ceph_mds

~> **Experimental.** Schema and behavior may change in future releases. Pin the provider version if stability matters.

Manages a Ceph metadata server (MDS) on a Proxmox VE node. CephFS needs a running MDS, and Proxmox VE only creates a CephFS while one is in standby.

Creation finishes once Proxmox VE has started the daemon, without waiting for it to join the Ceph cluster.

~> Destroying an MDS stops it even while it serves a CephFS, as the Proxmox VE web UI does. A standby MDS takes over if there is one; otherwise the filesystem is unavailable until another MDS starts.

## Example Usage

```terraform
resource "proxmox_ceph_mds" "example" {
  node_name = "pve"
  name      = "pve-mds"
}
```

## Schema

### Required

- `name` (String) The MDS ID, unique within the Ceph cluster. It must start with a letter and contain only letters, digits and hyphens, not ending with a hyphen.
- `node_name` (String) The node that runs the MDS.

### Read-Only

- `id` (String) The unique identifier of the MDS: its ID within the Ceph cluster, the same as `name`.

## Import

Import is supported using the following syntax:

```shell
#!/usr/bin/env sh
# Ceph metadata servers can be imported using the format `node_name/name`, e.g.:
```
