# Resource: proxmox_sdn_controller_bgp

The BGP controller configures the Free Range Routing (frr) BGP router of a single node. Proxmox allows at most one BGP controller per node, and none while a BGP fabric is configured. SDN changes must be applied with the proxmox_sdn_applier resource before they affect the network.

## Example Usage

```terraform
# SDN Controller (BGP) - Example configuration for a BGP controller on a single node
resource "proxmox_sdn_controller_bgp" "example_controller_bgp" {
  id        = "bgp1"
  node_name = "pve"
  asn       = 65000
  peers     = ["10.0.0.1", "10.0.0.2"]

  ebgp                        = true
  ebgp_multihop               = 3
  bgp_multipath_as_path_relax = true

  depends_on = [
    proxmox_sdn_applier.finalizer
  ]
}

resource "proxmox_sdn_applier" "controller_applier" {
  depends_on = [
    proxmox_sdn_controller_bgp.example_controller_bgp
  ]
}

resource "proxmox_sdn_applier" "finalizer" {
}
```

## Schema

### Required

- `asn` (Number) Autonomous System Number of the local BGP router.
- `id` (String) The SDN controller object identifier.
- `node_name` (String) Name of the node this BGP controller is bound to. Required by the BGP controller plugin.
- `peers` (Set of String) Set of BGP peer IP addresses for the BGP controller.

### Optional

- `bgp_multipath_as_path_relax` (Boolean) Whether different AS paths of equal length are considered for multipath computation.
- `ebgp` (Boolean) Whether eBGP is used (remote-as external) instead of iBGP.
- `ebgp_multihop` (Number) Maximum amount of hops for eBGP peers. Requires ebgp set to true.
- `loopback` (String) Name of the loopback/dummy interface that provides the Router-IP.

### Read-Only

- `digest` (String) Digest of the controller section.

## Import

Import is supported using the following syntax:

```shell
#!/usr/bin/env sh
# SDN controller can be imported using its unique identifier (controller ID)
terraform import proxmox_sdn_controller_bgp.example_controller_bgp bgp1
```
